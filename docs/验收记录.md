## 未验证和环境限制

- 没有可用的远端小程序 ID 和登录环境，未创建线上榜单。真实成绩提交、跨用户排行、账号变化和真机存储尚未验收。
- 当前浏览器自动化工具能够读取官方 Mock 的受控 iframe，但向该 sandbox iframe 发送点击/键盘会返回控制目标不可用；因此没有把平台交互流程声称为 UI 验收通过。SDK 适配层使用独立单元测试验证，真实流程需绑定后再测。
- Browser Mock 的 screenshot 只能确认参数，不能生成实际分享图片。真实截图水印、相册、社区发送、PC 回退链接需真机验收。
- 减少动态效果及高对比度降级已实现并进行代码检查；未切换真实系统辅助功能设置，未进行屏幕阅读器或全套无障碍审计。
- `hb-sdk doctor` 的项目级 Skill 检查为 OK；多个未安装的全局 Agent 目录会使总体状态显示 SKILL_MISSING。未修改这些全局目录。
- 开发时改变自定义 Hook 的数量，旧热更新状态可能不兼容；通过页面“重新打开”恢复后，冷启动及正常流程均可运行。生产包不包含热更新。
