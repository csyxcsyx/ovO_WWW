# 官网鉴定局

从三个网址中找正版、辨冒牌、拼眼力。一个在小黑盒小程序工坊运行的网址辨认游戏，包含 166 个已核验网站、1847 道题目。

## 玩法

- **限时竞速**：60 秒内尽可能多答对，答对得分、连击加分，答错扣 3 秒。
- **生存挑战**：每题 12 秒、三次机会，按答对题数排名。
- 找正版、找冒牌、一字之差和混合迷惑交替出现，少量格式题只判断书写规范。
- 前 5 题按简单/中等 3:2 热身，第 6～10 题为 1:3:1；之后每 20 题按简单/中等/困难 5:8:7 混合，困难题最多连续两道。
- 最近 5 题覆盖至少 3 种挑战，最近 8 题避免重复网站，同类别最多连续两题；格式题从第 11 题开放，每连续 20 题最多一道。
- 赛后可查看逐题解析、本机纪录和云端排行，成绩自动同步，支持成绩分享。沿用原有计分与排行榜，新旧成绩继续有效。
- 排行榜每批加载 20 条，滑到底部自动追加；切换玩法或关闭重开会保留当前会话的列表与滚动位置。

网址选项仅作为文本展示，不跳转。支持触屏与键盘操作：`1` / `2` / `3` 作答，`Tab` / `Enter` 导航。

## 本地运行

使用 Node.js ≥ 22.20.0 和 npm：

```powershell
npm ci
npm run dev -- --no-open
```

打开终端输出的官方 Browser Mock 调试页。榜单和分享等能力需在小黑盒中联调。

也可运行 `npm run dev:web`，在 `http://127.0.0.1:4173/` 体验离线答题和本机纪录。

## 开发

React + TypeScript + Vite，使用官方 `@heybox/hb-sdk` 接入平台能力，无自建服务器。

- `src/components`：界面组件。
- `src/game`：抽题、计时与计分。
- `src/platform`：平台适配、纪录与榜单同步。
- `src/data`：网站资料与题库。
- `scripts` / `assets`：数据维护与发布素材。

```powershell
npm run typecheck
npm test
npm run validate:questions
npm run build
```

核心回归测试与代码放在同一目录，抽题测试覆盖 100 个固定种子各 100 题。构建产物位于 `dist/`，本地生成文件位于 `output/`，均不入库。

开发、真机联调、权限和提审流程见 [小黑盒开发发布指南](docs/小黑盒开发发布指南.md)。原始题库及来源核验资料保留在 `docs/`，数据变更需重新核验。
